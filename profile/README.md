## What RigorousLab does

RigorousLab is a statistical verification platform for researchers. It turns raw result files (CSV, JSON, NumPy) into publication-ready LaTeX tables and runs standard statistical checks, so every number in a paper can be traced back to its data.

**Checks included:** normality checks and t-tests · bootstrap confidence intervals · power analysis · verified statistics packaged together with the paper for review.

**Status:** controlled public beta.
